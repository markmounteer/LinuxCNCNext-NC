## Data-driven grammar

The verifier compares the entire Rust grammar with the legacy contract. Each
entity arity and every named attribute (including nested choices, reference target
types, aggregates, bounds, symbols and context-sensitive dimensions) is enumerated
in the JSON inventory. The same check compares all complex-component combinations.
Rust's recursive matcher and SI/non-SI dimensions dispatch enforce the same data.
